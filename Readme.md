# TaskFlow Productivity Tracker 
A modern productivity tracking web application designed to help users manage daily tasks, maintain consistency, build productive habits, and monitor progress through streaks, achievements, and activity tracking.

## Project Overview

TaskFlow Productivity Tracker v2 is a feature-rich task management application built using HTML, CSS, and JavaScript. The application goes beyond a traditional Todo App by incorporating productivity-focused features such as streak tracking, achievement badges, daily task resets, activity history, and calendar-based progress visualization.

## Features

### Task Management

* Create new tasks
* Edit existing tasks
* Mark tasks as completed
* Undo completed tasks
* Delete tasks
* Real-time task statistics

### Daily Productivity System

* Automatic daily task reset
* Fresh workspace every day
* Daily productivity tracking
* Historical task archiving

### Achievement System

* 🥉 Bronze Badge – 50 completed tasks
* 🥈 Silver Badge – 100 completed tasks
* 🥇 Gold Badge – 500 completed tasks
* 💎 Platinum Badge – 1000 completed tasks
* 🏆 Daily Warrior Badge – 7-day streak

### Streak Tracking

* Consecutive productive day tracking
* Automatic streak updates
* Streak reset on missed days

### Activity Calendar

* Monthly productivity visualization
* Active day highlighting
* Consistency tracking

### History Tracking

* Daily productivity records
* Completed task history
* Streak history records

### Data Persistence

* Local Storage integration
* Automatic data recovery after refresh
* Persistent task and achievement data

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript (ES6+)

### Browser APIs

* Local Storage API
* Date API
* DOM Manipulation

## How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/taskflow-productivity-tracker-v2.git
```

2. Open the project folder

```bash
cd taskflow-productivity-tracker-v2
```

3. Run using VS Code Live Server

or

Open `index.html` directly in your browser.
